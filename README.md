# AI-Assisted Helpdesk Ticket System

## Description
A full-stack web application to manage and resolve support tickets efficiently using AI-based prioritization.

## Features
- Role-based login (Admin/User)
- Ticket CRUD operations
- Search and filter
- AI-based priority classification
- Excel report generation

## Tech Stack
- Java (JSP, Servlets)
- MySQL (JDBC)
- HTML, CSS

## How to Run
1. Clone the repo
2. Open in IntelliJ
3. Configure database
4. Run on Tomcat server
